# FG-TIDA analysis

Reproducible analyses contributed by Himalogic Software Pvt. Ltd. to the ITU-T Focus Group on Trust and Identity for Humans and Agentic AI (FG-TIDA).

Each analysis lives in its own directory, is written against a pinned version of its source data, and regenerates every figure cited in the corresponding FG-TIDA discussion.

## Analyses

| Directory | Question | Discussion |
|---|---|---|
| [`judge-agreement/`](judge-agreement/) | Inter-judge agreement on the CTGT lineage-eval matched-v2 release | [FG-TIDA/themes#21](https://github.com/FG-TIDA/themes/issues/21) |
| [`planted-judge/`](planted-judge/) | Whether a population of judges exposes a planted judge without marking a justified dissenter, on TIDA6-FX-0.2 (specification, posted before any run) | [FG-TIDA/themes#21](https://github.com/FG-TIDA/themes/issues/21) |
